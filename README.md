# 🧮 Python Calculator Project

A clean, text-based calculator project built using Python. This project was developed to practice, polish, and reinforce the foundational building blocks of core programming.

## 🧠 Core Programming Concepts Covered
* **Python Programming Basics:** Structuring clean code, executing functional blocks, and accepting interactive user input through the terminal.
* **Variables:** Creating and utilizing variables to dynamically store numbers, arithmetic operators, and computational results in memory.
* **Conditional Logic (if-elif-else):** Building a robust decision-making structure to evaluate which operator (+, -, *, /) the user chose and execute the corresponding mathematical calculation.
